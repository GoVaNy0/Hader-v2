# Front Skill (Anti-Vibe & Craft Engineering)

Enforce authentic craftsmanship, production-grade systems engineering, and razor-sharp UI/UX while eliminating generic "AI vibe coding" patterns and template clichés.

> **Visual Design Reference:** Always cross-reference and apply the design tokens (colors, radii, elevations, and typography) defined in `./design.md`.

---

## When to Use

- Building or refactoring web applications, portfolios, SaaS interfaces, and landing pages.
- Reviewing UI code generated by AI models to strip out superficial decorative clutter.
- Establishing high-trust, engineered frontend components with authentic micro-interactions.

---

## 1. What to Eliminate (The "AI Vibe Coding" Hall of Shame)

Root out and remove these generic, overused patterns:

- **Fake Status Indicators:** Gratuitous pulsing dots, fake green pills, `SYS_STATUS: 200 OK`, or terminal gimmicks on non-terminal products.
- **Generic Role Badges & Pill Clutter:** Badges like "Available for Hire", "Full-Stack Web Developer", or floating pill tags above headlines that add zero information.
- **Neon Blur Soup:** Giant, unmotivated purple/cyan radial blur blobs (`bg-purple-500/20 blur-3xl`) slapped in the background to disguise lack of layout structure.
- **Decorative Clutter Without Function:** Random circuit lines, fake binary code, meaningless grid overlays, mock terminal prompts (`cairo_node_01`), or fake telemetry counters.
- **Superficial Glassmorphism:** Heavy, unreadable `backdrop-blur-md` containers with thick, low-contrast borders that destroy typography hierarchy.
- **Lover of Cards Syndrome:** Wrapping every single sentence or keyword in its own tiny bordered card or bento box.

---

## 2. Production-Grade Replacement Rules

Apply intentional design engineering:

### Typography and Hierarchy First
- Rely on scale, line-height, letter-spacing, and weight rather than decorative containers.
- Use distinct, authentic font pairs (e.g., editorial sans paired with precise mono only for actual technical data).
- Let headlines breathe with generous, deliberate whitespace.

### Structural Depth Over Cheap Glows
- Replace loud radial glows with subtle, hairline borders (`border border-white/[0.08]`) and soft, multi-layered ambient elevations (`shadow-2xl shadow-black/50`).
- Use warm charcoal or deep obsidian backgrounds (`#09090b`, `#0c0c0e`) rather than pure `#000000` with loud neon accents.

### Meaningful Micro-Interactions
- Animations must be functional, physics-grounded (spring transitions), and tied to real user input (hover tilt, smooth focus on scroll, crisp click feedback).
- Scroll dynamics must reach full focus early (e.g., `offset: ["start end", "start 65%"]`) so content is immediately readable without requiring precise scrolling stop-points.

### Concrete Information Over Vague Buzzwords
- Show real metrics, live links, and concrete architectures instead of abstract descriptions.
- Every button must do what it claims: live external links (`rel="noopener noreferrer"`), functional clipboard copy with timed state feedback, or direct communication channels.

---

## 3. Engineering Rigor & Code Quality

- **Zero TypeScript / Lint Errors:** Always verify all imports, types, and component exports (`export default function`).
- **Client vs. Server Separation:** Keep `'use client'` strictly on interactive leaf nodes.
- **Accessible & Responsive:** Proper ARIA labels, semantic HTML (`<main>`, `<article>`, `<nav>`, `<footer>`), and rock-solid mobile breakpoints.
